五個核心機制

  • 卡片裡沒有電池。端末機用 13.56 MHz 的交流電驅動一圈線圈，卡片內部是一組調諧在同一頻率的 LC 共振電路，把感應到的電壓整流、穩壓成約 1.8 V。
  • 兩個方向用完全不同的手段講話。端末機用 100% 振幅調變，把資料藏在「暫停出現的位置」；卡片沒有發射器，改用負載調變，在 847.5 kHz 的副載波上回話。
  • 卡片證明自己不是偽卡，靠的是三層憑證鏈：卡片公鑰由發卡行簽、發卡行公鑰由卡組織簽、卡組織公鑰內建在端末機裡。私鑰全程不離開晶片。
  • 金額不被竄改，靠的是另一套對稱金鑰算出的 ARQC 密文。銀行端不逐卡保存金鑰，而是以發卡行主金鑰在硬體安全模組裡即時推導出來。
  • 同一套近場耦合原理，換個頻率與功率就變成無線充電、電磁爐、門禁卡、圖書館防盜門與高速公路上的 eTag。差別只在赫茲數與瓦數。

收銀台上的那台機器

把櫃檯上那台端末機拆開，裡面的東西比想像中多：正面是彩色顯示器與一排按鍵，按鍵底下是印刷電路板上的碳膜接點；側邊有一道磁條讀頭，是三十年前留下來的介面；機身內部有一顆熱感應印表機與一捲收據紙；還有一組無線網路或行動網路模組，負責把交易送上網。主機板底面則排著一列彈片接點，那是插卡式晶片讀卡槽的金手指，卡片插進去時靠這幾片彈簧鋼接觸。

真正跟這篇有關的，是從主機板拉出來的兩條線。它們接到一圈繞了好幾匝的漆包線或蝕刻銅箔——這就是近場通訊（Near Field Communication，NFC）天線。它的位置不是隨便擺的：線圈平面正好貼在機身外殼上那個「四道弧線」的感應符號底下。符號在哪裡，線圈就在哪裡。有些機型把它放在機身上緣，有些放在螢幕正下方，有些讀卡機乾脆整個面板都是線圈。這個符號的意義只有一個——它是磁場最強的位置。

為什麼位置這麼重要

單匝圓形線圈在其軸線上的磁場強度，與距離的關係是：

$$H(z)=\frac{N\,I\,a^{2}}{2\left(a^{2}+z^{2}\right)^{3/2}}$$

其中 a 是線圈半徑、N 是匝數、I 是電流、z 是軸向距離。當 z 遠小於 a，場強幾乎不變；一旦 z 超過線圈半徑，分母就以三次方增長，場強開始以 1/z³ 急速衰減。這就是為什麼感應距離被壓在幾公分：不是規格刻意限制，是物理本身的斜率太陡。規範要求端末機在工作區域內提供 1.5 至 7.5 A/m 的場強，過弱卡片開不了機，過強則可能讓卡片的保護電路持續洩流。

另一個被忽略的條件是角度。感應電壓正比於穿過線圈的磁通量，卡片立起來與磁力線平行時，通量趨近於零。卡片必須平貼、而且要位於線圈開口的範圍內，這也是刷不過時把卡片挪個兩公分就通了的原因。

隔空供電的物理

端末機在等待狀態下，會持續用 13.56 MHz 的交流電驅動那圈線圈。交流電產生的是一個同頻振盪的磁場，覆蓋範圍大約是端末機表面上方幾公分的空間。當卡片被放進這團看不見的場裡，卡片內部的線圈會因為穿過它的磁通量不斷變化而產生感應電動勢，這就是法拉第感應定律：

$$\varepsilon = -N\frac{\mathrm{d}\Phi_{B}}{\mathrm{d}t}$$

負號來自冷次定律，意思是感應電流所產生的磁場會反抗原來的變化。這個細節等一下會變成整篇文章最關鍵的機制——卡片就是靠「反抗得多一點或少一點」來講話的。

值得先釐清一個常見誤解：這裡完全沒有無線電波在傳播。13.56 MHz 的波長約 22 公尺，而收發距離只有幾公分，遠遠落在近場區內。能量不是被輻射出去再被接收，而是兩個線圈透過互感直接耦合，行為上更接近一具氣隙很大的變壓器。端末機線圈是初級側，卡片線圈是次級側，只是中間隔著空氣、塑膠與你的皮夾。

RFID 防盜皮夾是怎麼擋的

內襯一層導電材質即可。外來的交變磁場會在這層金屬上感應出渦流，渦流又產生反向磁場，兩者相消，同時也把卡片天線的共振點拉歪。實際上多數皮夾裡本來就有金屬扣或多張卡互相干擾，本來就常常刷不過——那其實是同一個物理效應在幫倒忙。

卡片裡的兩片金屬

把一張感應式信用卡對著強光看，會隱約看到一圈環繞整張卡的迴路。它的做法是在兩層薄塑膠之間夾進兩片沖壓或蝕刻成型的金屬薄片，再用貫孔把上下兩片在特定位置接通，讓整條路徑串成一個連續的多匝迴圈。這圈迴圈就是電感。

但金屬片上不只有迴圈。仔細看還會發現幾條平行的長條，以及一整片排列整齊的矩形小塊——它們與另一層金屬隔著薄塑膠相對，構成平行板電容。電感加上電容就是 LC 諧振電路，共振頻率為：

$$f_{0}=\frac{1}{2\pi\sqrt{LC}}$$

製造時會把 L 與 C 湊到讓 f₀ 落在 13.56 MHz 附近（實務上通常刻意調高一點，補償貼在人體或其他卡片旁邊造成的偏移）。共振的目的不只是「對上頻率」這麼簡單：在共振點上，電路的品質因數 Q 會把線圈兩端的電壓放大好幾倍，讓微弱的感應訊號足以驅動整流器。沒有這個放大，幾公分外的磁場根本點不亮晶片。代價是 Q 越高、頻寬越窄，資料邊緣就越糊，所以卡片設計始終在「拿得到電」與「聽得清楚」之間折衷。

金屬片上還有第三個元件：一個面積小得多的線圈，而 EMV 晶片模組正好坐在它中央。這裡藏著一個製造上的巧思——晶片模組本身也帶著自己的小線圈，兩者隔著空氣與膠層互相感應耦合，中間沒有任何焊點或導電膠。業界稱之為模組線圈（coil on module）搭配增益天線（booster antenna）。

這麼做的理由純粹是經濟與良率。卡體的層壓與金屬沖壓可以在一條產線上大量生產，晶片模組則在半導體廠另外做，最後只要把模組壓進卡片上挖好的凹槽、對準位置即可，不必逐張做電氣連接。焊接點是感應卡最容易失效的地方，卡片被折彎、被塞在後口袋坐了三年，斷的幾乎都是那兩個接點。取消接點，可靠度直接跳一級。

晶片模組內部

  • 打線　模組線圈的兩端以髮絲般的金線接進晶片，把感應到的交流電壓送進去。
  • 整流與穩壓　橋式整流把交流變成脈動直流，穩壓器再壓成穩定的 1.8 V 供數位電路使用。旁邊還有一組限幅電路：當卡片貼得太近、場強過大時，多餘的能量必須被洩掉，否則會打穿閘極氧化層。
  • 時脈回復　晶片不需要石英振盪器，它直接從 13.56 MHz 載波分頻取得系統時脈。端末機不只供電，也供時間基準。
  • 安全微控制器　32 位元核心，加上 RSA 與 AES 的硬體協處理器、真亂數產生器，以及電壓、頻率、溫度、光線的異常偵測器。偵測到異常就重置，這是對抗故障注入攻擊的第一道防線。
  • 非揮發記憶體　存放卡號、有效期、憑證與金鑰。晶片頂面通常還鋪有金屬遮蔽層，開蓋探針就會斷線。

整顆晶片包在一滴環氧樹脂底下，另一面則是那片熟悉的金色接觸墊。那些墊子除了在插卡時當介面，也是產線上寫入卡號、金鑰與憑證的唯一通道——這道「個人化」程序完成之後，金鑰寫入路徑就被永久關閉，之後再也讀不出來。

輪詢、UID 與防碰撞

晶片通電之後幾毫秒內完成重置，這時端末機其實一直在喊話。在等待付款的整段期間，它會週期性地送出一個很短的請求指令，內容大意是「場內有卡嗎」。卡片一旦取得足夠電力，就以自己的類型代碼回應，接著雙方進入防碰撞程序。

防碰撞要解決的是很實際的問題：皮夾裡可能同時有信用卡、悠遊卡與門禁卡，三張一起進場、一起回話，訊號會疊在一起。規範採用位元層級的二元樹搜尋——端末機先廣播「唯一識別碼的第一個位元是 0 的請回答」，發生衝突時再往下切一層，逐位元收斂，直到場內只剩一張卡在回應。識別碼長度有 4、7、10 個位元組三種規格，後兩種要分多輪完成。

這裡有個常被誤傳的細節：多數感應式信用卡並不會固定回傳一組專屬的識別碼。為了避免被沿街掃描的裝置當成追蹤用的指紋，它們每次上電都重新抽一組隨機識別碼回應（以 0x08 開頭的 4 位元組形式），下次靠上去就換一組。真正用來辨識帳戶的資料在後面的加密流程才出現，識別碼在這裡只負責一件事——讓端末機在多張卡之中挑出一張來對話。

選定之後，端末機送出請求，把通訊升級成半雙工的區塊傳輸模式，往後所有訊息都以應用協定資料單元（Application Protocol Data Unit，APDU）的格式往返。到這一步，實體層的工作算是完成了；但在進入支付邏輯之前，值得先把「這些位元到底怎麼飛過那幾公分」講清楚，因為兩個方向用的是兩套完全不同的物理。

兩張卡同時放上去會怎樣

防碰撞機制本身有能力挑一張出來，但支付規範刻意不讓它這麼做。端末機一旦偵測到場內不只一張卡，必須中止並提示使用者把卡片分開——因為「機器替你決定要扣哪張卡」是不可接受的。這也是把整個皮夾往感應區拍下去常常失敗的原因，那通常不是感應不良，而是卡片衝突。

端末機怎麼說話

端末機已經在放出一個振盪磁場供電了，最省事的做法就是讓同一個場順便載資料。於是它把 13.56 MHz 的載波切成等長的時槽，每個時槽剛好 128 個載波週期，一個時槽送一個位元。傳輸率因此是一個除法的結果：

$$\frac{13.56\times10^{6}}{128}=105\,937.5\ \text{bit/s}$$

業界習慣把它叫做 106 kbit/s。同一套實體層也定義了 212、424、848 kbit/s 的高速模式，做法是把每個時槽縮短成 64、32、16 個週期，但支付交易的起手式一律從 106 kbit/s 開始。

最直覺的編碼方式是：振幅滿載代表 1、振幅減半或歸零代表 0。這個做法有個致命問題——資料裡出現一長串 0 時，磁場就等於被關掉一段時間，卡片沒有電池，電容存的那點電撐不了多久，晶片會直接斷電重置。

規範給出的解法叫做修正式米勒編碼（modified Miller coding）。載波維持滿振幅，只在每個時槽裡插入一段極短的凹陷——大約 2 到 3 微秒的「暫停」，相當於 128 個週期裡只挖掉約 30 個。資料不是由振幅高低表示，而是由暫停出現在時槽中的位置表示：

修正式米勒編碼　載波被挖出的凹陷位置就是資料

0 1 0 1 1 0 0 1

虛線切出的每一格是一個時槽，等於 128 個載波週期；格內的深色缺口就是那段 2–3 微秒的暫停。

  • 位元 1　暫停落在時槽正中央。
  • 位元 0　暫停落在時槽起點。
  • 例外　前一個位元是 1 的時候，緊接著的 0 完全不放暫停（上圖第三與第六個時槽）。因為前一位元中央那個暫停已經提供了足夠的邊界資訊，再放一個反而會與它靠得太近、無法分辨。

結果是：不管資料內容是什麼，載波的平均功率幾乎維持不變，卡片不會因為連續的 0 而斷電；同時每個暫停都是一個銳利的時序邊緣，卡片可以靠它校準自己的取樣時點。一舉兩得。

這套下行方案在規範裡稱為 Type A，用的是 100% 振幅鍵移（Amplitude Shift Keying，ASK），也就是暫停期間載波完全關閉。同一份規範還有一套 Type B：振幅只調變約 10%，載波從不完全關閉，資料以不歸零編碼直接對應高低振幅。兩者的取捨很典型——Type A 的邊緣乾淨、解碼電路便宜，但關閉載波的那一瞬間卡片完全沒有能量進帳；Type B 供電連續、對干擾較寬容，但需要比較講究的類比前端。臺灣市面上的感應卡與交通票證絕大多數屬於 Type A。

卡片怎麼回話

卡片的處境比較尷尬：它沒有電池，也沒有發射器，所有能量都來自對方的場。既然造不出自己的訊號，它就改去干擾對方的訊號。

先用一個粗糙但精準的類比。假設你手裡緊握一塊強力磁鐵，另一個人拿一塊鐵板在磁鐵前面來回移動：鐵板靠近時，你感覺到磁鐵被往前拉；鐵板移開，那股力量就消失。你完全不必看，光靠手上的力道變化就能知道對方在做什麼——甚至可以請對方用「靠近＝1、遠離＝0」跟你溝通。

端末機的處境就是握磁鐵的那隻手。卡片當然不會真的前後移動，它改變的是自己從場裡取走多少能量：晶片內部有一顆電晶體控制著一組分流電阻，電晶體導通時電阻接上線圈，卡片瞬間多吸走一些能量，稱為高負載；電晶體關閉時這條路徑斷開，卡片吸得少，稱為低負載。

這個變化會透過互感回頭反映在端末機的線圈上——耦合電路裡稱為反射阻抗。端末機在聆聽時把自己的輸出維持在穩定振幅，同時緊盯自己線圈上的電壓與電流，卡片每切換一次負載，它就讀到一次擾動。這種手法叫做負載調變（load modulation）。整個過程是半雙工：同一時間只有一方能說話。

最常被略過的那一層：847.5 kHz 副載波

卡片造成的擾動非常微弱，落在端末機自身載波的千分之幾。如果直接把負載的高低當成資料，這點變化會被自己數十伏特的振盪完全淹沒。實際做法多一層轉換：卡片先把資料編碼，再用它去開關一個 847.5 kHz 的副載波（正好是載波的十六分之一，13.56 MHz ÷ 16），最後才以這個副載波去切換負載。

這麼一來，回傳的能量被搬到距離載波 ±847.5 kHz 的兩條邊帶上。端末機只要用帶通濾波器把中央那根巨大的載波濾掉，剩下的就是乾淨的回傳訊號。這是整套系統裡最漂亮的一步：把「聽不見的耳語」搬到一個沒有人在喊的頻率上。

1 0 1 1 0 0 1 0

高的色塊代表高負載、矮的代表低負載。注意翻轉只發生在每一格的正中央；格與格之間的交界即使準位相同也不影響解碼。

上行資料同樣以 128 個載波週期為一個時槽。如果照樣用「高負載＝1、低負載＝0」，一串連續的 1 會讓負載完全不動，端末機無法判斷卡片是在送資料還是已經離開。曼徹斯特編碼（Manchester coding）強制每個時槽的中央一定發生一次翻轉：低轉高代表 1，高轉低代表 0。時槽邊界上也可能因為相鄰位元而出現額外的翻轉，但那些不帶資訊，解碼時只看中央那一次。

代價是頻寬翻倍：每個位元至少要兩次準位變化。換來的是時脈內嵌在資料裡，接收端不需要另外一條時脈線，也不會因為長串相同位元而失去同步。乙太網路早期的實體層用的是同一招。

選應用與定規則

實體層接通之後，剩下的都是對話。一張卡片上可能同時住著好幾個支付應用：一個國際卡組織的、一個本地清算的、也許還有一個交通票證的。端末機的第一件事是問清楚「你身上有哪些應用，我支援哪幾個」。

做法是先選一個固定名稱的目錄檔——非接觸交易用的是 2PAY.SYS.DDF01，卡片回傳一張清單，列出自己支援的各個應用識別碼（Application Identifier，AID）與優先順序。端末機拿這張清單跟自己支援的交集比對，挑出優先權最高的一個，正式選定。

接著端末機送出取得處理選項的指令，並依照卡片指定的欄位清單附上這次交易的背景資料：金額、幣別、交易國別、終端機類型、終端機能力、日期，以及一個當場產生的不可預測數。卡片收下之後回覆它要求端末機讀取哪幾筆檔案紀錄，端末機再逐筆讀回卡號、有效期、持卡人驗證方式清單，以及後面驗證要用的憑證。

不同卡組織在這一段的細節並不一致，規範因此把非接觸流程拆成數個獨立的核心（kernel），各自對應一家卡組織的規則。表面上看起來都是「嗶一聲」，底下跑的可能是完全不同的指令序列與風險判斷。

臺灣現場：免簽名的那條線

持卡人驗證方式在這一步就決定了。依金管會規定，國內免簽名交易單筆金額不得超過新臺幣 3,000 元；超過就必須改以簽名、輸入密碼，或請你改插卡。同一份規範還要求收單機構督促特約商店把感應器裝在結帳櫃檯前方、面向持卡人，而且必須由持卡人自己持卡完成，店員不得代為操作。

這條線的意義是風險上限：在它之下，系統選擇用速度換取一點點被冒用的機率，因為爭議款的處理成本低於排隊時間的成本。綁在手機上的支付不受這個門檻拘束，因為指紋或臉部辨識本身就算完成了持卡人驗證。

卡片證明自己是真的

到這裡出現整段流程中第一個真正的安全難題：端末機怎麼知道面前這張卡是銀行發出來的，而不是一張偽卡或一台模擬裝置？

銀行在寄卡給你之前，已經在晶片裡寫進一把專屬的祕密金鑰。問題是這把金鑰不能送出去——空中的訊號可以被旁邊的裝置錄下來，送一次就等於公開一次。所以真正的問題是：如何證明自己知道一個祕密，而完全不透露這個祕密。

答案是非對稱式加密（asymmetric cryptography），也叫公開金鑰加密。除了藏在卡裡的私鑰之外，還有一把成對的公鑰，可以任意散布而不會洩漏私鑰的內容。兩把金鑰在數學上配成一組：私鑰處理過的資料只有公鑰能還原，反之亦然。

驗證的動作因此變成一場挑戰與回應：端末機產生一個當場才決定的亂數送給卡片，卡片用私鑰對它（連同這次交易的若干欄位）做簽章，端末機用公鑰驗證簽章。驗得過，就代表對面握有那把私鑰。亂數每次都不同，所以錄下上一次的回應也無法重放。

但新的問題立刻出現：全世界流通的卡片數以十億計，端末機不可能把每張卡的公鑰都存起來。卡片只好自己把公鑰交出去——這聽起來很循環：既然公鑰是卡片給的，端末機憑什麼相信它不是偽造的？

三層憑證鏈　信任從端末機裡的那一把往下延伸

  1. L1 卡組織的憑證中心　每家卡組織自己維運一套公開金鑰基礎架構，扮演憑證中心的角色。它的公鑰隨著端末機的認證程序預載進去，並以一個索引編號標示是哪一把。這是整條鏈的信任起點。
  2. L2 發卡行憑證　憑證中心用自己的私鑰，對發卡銀行的公鑰加上識別碼、有效期、序號等欄位簽章，產出發卡行公鑰憑證。這份憑證存在卡片裡。
  3. L3 卡片憑證　發卡行再用自己的私鑰，對這張卡的公鑰與卡號簽章，產出卡片公鑰憑證，一併寫進晶片。

驗證時倒著走一遍：端末機依索引取出卡組織公鑰 → 驗開發卡行憑證、取得發卡行公鑰 → 驗開卡片憑證、取得卡片公鑰 → 用卡片公鑰驗證剛才那個亂數的簽章。四個步驟全過，才認定這張卡是真的。

常見的簡化說法是「卡組織直接簽了卡片的公鑰」。實際上中間還隔著發卡行這一層，這層存在的理由很現實：卡組織不可能為全球每一張卡逐一簽章，它只簽幾百家銀行，剩下的交給銀行自己簽。

感應交易對這一段另有嚴格規定。純靜態的資料認證（把一份固定簽章存在卡裡）在非接觸交易中完全不被允許，因為固定簽章可以被複製到偽卡上。實務上使用的是快速動態資料認證（fast DDA）或複合式動態認證（Combined DDA/AC Generation，CDA）——後者把動態簽章與下一節的密文產生合併成一個步驟同時完成，既省時間，也讓簽章與交易密文綁在一起，無法拆開替換。

底層的數學是單向陷門函數：往一個方向算很容易，反過來極其困難。以 RSA 為例，把兩個大質數相乘是瞬間的事，但只給你乘積要反推出那兩個質數，在目前的算力下不可行。簽章與驗證分別是下面兩個模冪運算：

$$s = m^{d} \bmod n \qquad m = s^{e} \bmod n$$

其中 d 是私鑰指數、e 是公鑰指數（EMV 實務上常用 3 或 65537，好讓端末機那側的驗證特別快）、n 是兩個質數的乘積。

這裡有一個少被提及的限制：EMV 的資料格式讓公鑰模數最長只能到 1,984 位元。這個上限來自指令封包的長度限制，已經逼近舒適區的邊緣——美國國家標準暨技術研究院早已宣告 2030 年後不再支持這個長度，EMVCo 也已發布支援橢圓曲線密碼學的規格，準備把整條憑證鏈換成金鑰更短、運算更省的曲線運算。這是一次需要同步更換全球數千萬台端末機與數十億張卡片的遷移，會花上很多年。

不過真正值得記住的是這套設計的核心性質：從頭到尾，卡組織的私鑰沒有離開過它的憑證中心，發卡行的私鑰沒有離開過它的硬體安全模組，你那張卡的私鑰沒有離開過那顆晶片。空中傳過的全是公鑰、憑證與簽章——就算整段通訊被完整錄下，也複製不出一張能用的卡。

把金額鎖進密文裡

卡片是真的，不代表交易內容是真的。端末機接下來要把金額、卡號、日期、商家代碼與所在國別等資料，經由收單機構與清算網路送到發卡銀行請求授權。這條路徑很長，中間經過的節點不只一個，於是出現第二個威脅：如果端末機本身被動過手腳，螢幕上顯示 17 元，送出去的卻是 1,000 元呢？

擋住這件事的是對稱式加密——同一把金鑰既用來產生也用來驗證，而且這把金鑰跟前一節的公私鑰完全無關，是另一套獨立的體系。

流程是這樣：端末機把整包交易資料交給卡片，卡片用自己的金鑰對它做運算，產出一段固定長度的密文，稱為授權請求密文（Authorisation Request Cryptogram，ARQC），交還給端末機。端末機把這段密文連同未加密的交易資料原文一起送去銀行。銀行拿原文用自己那邊的金鑰重算一次，如果算出來的結果跟卡片送來的那段一模一樣，就代表雙方看到的是同一份資料——中途任何一個欄位被改過，密文都會完全對不上。

銀行並沒有替每張卡存一把金鑰

「卡片裡一把、銀行伺服器裡一把」是個方便但不精確的說法。實際上金鑰是逐層推導出來的：

  1. ① 發卡行主金鑰　只存在銀行的硬體安全模組裡，從不以明文離開。
  2. ② 卡片專屬金鑰　以主金鑰搭配卡號（與卡片序號）分散運算而得，在個人化階段寫入晶片。每張卡都不一樣。
  3. ③ 單次交易金鑰　再以卡片專屬金鑰搭配應用交易計數器（每做一次交易就加一）推導而得，因此每一筆交易用的金鑰都不重複。

密文本身以三重資料加密標準（3DES）或進階加密標準（AES）計算。銀行收到授權請求時，拿著卡號與計數器現場把 ② 和 ③ 重推一遍、重算密文比對即可，完全不需要為幾千萬張卡維護一張金鑰表。計數器只增不減，也讓錄下來的舊密文無法重放。

驗證通過、額度足夠、風險模型也沒有亮紅燈之後，銀行送回的不只是一句「核准」。它會用同一套金鑰體系算出一段授權回應密文（Authorisation Response Cryptogram，ARPC）一併回傳——這是反方向的證明：讓卡片確認這個回覆確實來自自己的發卡行，而不是某人在半路偽造的。卡片若仍在感應區內，會驗證這段密文並更新自己的離線風險參數。

整整一秒裡，真正花時間的其實是這一段。卡片的密文運算是毫秒級，密碼學不是瓶頸；瓶頸是端末機經收單機構、卡組織網路到發卡行主機再折返的那趟來回。感應動作結束後你可以把卡片收起來，畫面卻還停在等待——那不是卡片還在算，是封包還在路上。

核准，以及後面那幾天

回應抵達，端末機嗶一聲，螢幕亮起綠色的核准，印表機開始吐收據。這一秒到此結束。

但錢還沒有動。授權做的事情只是在你的信用額度上凍結一筆金額，並取得一組授權碼。真正的資金移動發生在清算與結算：商家通常在當日營業結束後把一整批授權送出請款，收單機構彙整後交給卡組織，卡組織計算各家銀行之間的淨額，隔天或再隔幾天才完成撥款。刷卡當下看到的「已扣款」是額度被佔住，不是錢已經離開帳戶——退款之所以要等好幾天，多半卡在這段批次流程，而不是誰在拖延。

還有一條分支值得一提。如果端末機當下連不上網——飛機上的機上購物、隧道裡的收費站、網路中斷的小店——流程不會直接失敗。卡片與端末機各自帶著一組風險參數：單筆離線上限、累計離線金額上限、連續離線次數上限，還有一個隨機抽樣的比例。金額夠小、離線次數還沒用完，卡片就直接產生一段代表「離線同意」的交易證明密文，讓交易先成立、稍後再補送；額度用盡或風險參數不允許，卡片則回覆拒絕密文，端末機顯示交易失敗。這些參數是發卡行寫進晶片的，等於把一部分風控邏輯直接下放到那張塑膠片裡。

規格11 / 14

這顆晶片有多強

前面那些運算——RSA 簽章驗證、三層憑證解封、3DES 或 AES 密文產生——全部要在一張沒有電池的塑膠片裡跑完，而且要在你把手縮回去之前跑完。

擔任這項工作的是一顆專為智慧卡設計的 32 位元安全微控制器。以市面上常見的規格來說，核心時脈約 60 MHz，旁邊掛著 RSA、AES、DES 的硬體加速器與真亂數產生器。把這個數字放到歷史座標上會有點奇妙的感覺：1994 年的第一代 PlayStation，主處理器是 33.87 MHz 的 32 位元 MIPS 核心。換句話說，你皮夾裡那張卡的運算能力，跟一台家用遊戲主機是同一個量級——而且它沒有電源線、沒有散熱片，功耗只有幾毫瓦，全部的能量來自幾公分外的一圈線圈。

更苛刻的是它的工作環境。這顆晶片必須假設攻擊者對它有完整的物理接觸：可以量測它的耗電曲線來推測金鑰（功率分析）、可以用雷射或電壓突波製造運算錯誤再從錯誤中反推（故障注入）、可以磨開封裝用探針接線。對應的防護因此也寫進矽晶片裡——讓加密運算的耗電趨於平坦、在指令之間插入隨機延遲、鋪設金屬遮蔽層、佈滿電壓與溫度感測器，一旦數值異常立即重置。一顆能通過支付產業認證的晶片，成本裡有相當比例是花在這些「不產生任何功能」的防護上。

風險12 / 14

還沒被解決的攻擊面

前面那套密碼學設計得相當紮實，但它保護的是「訊息的真偽」，不是「距離」。最有效的攻擊正好繞過所有加密：不破解任何東西，只是把對話原封不動地搬遠一點。

中繼攻擊

攻擊者準備兩台裝置：一台假扮成端末機，靠近受害者的口袋或皮夾；另一台假扮成卡片，貼在遠處某間店的真端末機上。兩台之間用網路連線，把每一道指令與回應即時轉送。對卡片來說它真的在跟一台端末機對話，對端末機來說它真的在跟一張卡片對話，所有簽章與密文都是真的——因為它們確實是由真卡即時產生的。學界的展示顯示，僅用被動的線圈中繼就能把原本 4 公分的有效距離拉到將近 50 公分，若改用手機轉送，距離幾乎不受限制。

對策：測時間，不測內容

既然訊息本身無懈可擊，防線只能改放在時間上。距離界定協定的做法是讓端末機發出一連串挑戰位元，並以奈秒級精度量測卡片回應所需的往返時間；電磁訊號的傳播速度是固定的，時間超出容許範圍就代表對方不在感應區內。這需要在實體層加入專門的快速交換機制，已有卡組織在自家的非接觸規格中採用類似設計。行動裝置則多一條路：用加速度計、陀螺儀等環境感測資料比對付款當下的情境是否合理。

其他被研究過的路徑

降級攻擊——設法讓端末機或卡片退回較舊、較弱的驗證流程；把偷來的卡片資料綁進攻擊者手機的電子錢包，再由車手到處感應；以及最老的一招，直接讀取磁條。這也是為什麼免簽名門檻存在：把單筆風險壓在一個金額之下，讓攻擊的報酬率低到不值得。

把尺度拉開來看，感應式晶片卡仍然遠比它取代的東西安全。磁條的做法是把帳號與有效期直接以磁化形式印在卡背，任何一台讀頭讀到就能完整複製，而且複製出來的卡與正本沒有差別。晶片卡的每一筆交易都帶著一段只能用一次的密文，錄下來也無法重放。攻擊沒有消失，但門檻從「買一台讀寫器」提高到「要即時中繼一張真卡」。

手機是怎麼假扮成卡片的

拆開手機，可以找到一圈專用的 NFC 天線（通常繞在背蓋內側或無線充電線圈旁）與一顆控制晶片。形狀完全不同，工作卻一樣：從端末機的磁場裡取得訊號、以負載調變回話。在實體層，手機與那張塑膠卡對端末機來說沒有差別，跑的是同一套規範。

不同的是憑證放在哪裡，以及送出去的卡號是不是真的。

多出來的兩層

  • 安全元件　手機內有一顆獨立於主處理器的認證晶片，作用與卡片裡那顆相同：金鑰進得去、出不來，作業系統也讀不到。另一種做法是主機卡模擬，把憑證放在雲端或以軟體保護，多用於門檻較低的應用。
  • 代碼化　綁卡時，卡組織的代碼服務商會為「這張卡在這支手機上」配發一組替身卡號，與真實卡號不同。同一張卡綁在手錶上會拿到另一組。因此商家與端末機自始至終看不到你的真實卡號，手機廠商的伺服器上也不存它。
  • 動態安全碼　每次付款時，安全元件產生一段只能用一次的密文隨替身卡號送出。替身卡號即使外流，少了當次密文也無法成立交易。
  • 持卡人驗證　付款前必須通過指紋、臉部辨識或密碼解鎖，這個動作本身就滿足規範中的持卡人驗證，所以行動支付不受免簽名金額門檻限制。

反方向也成立。手機可以切換成主動模式，自己產生 13.56 MHz 的磁場去供電並讀取一張卡片——這就是把手機當收單端末機的那些服務，讓小店不必再買一台專用機器。同一顆天線、同一套協定，角色對調而已。

同一個家族的其他成員

NFC 只是無線射頻辨識（Radio Frequency Identification，RFID）底下的一個分支。整個家族有上百種規格，但可以用一條界線切成兩半：靠電感耦合的近場，與靠電磁波傳播的遠場。分界大約落在 λ/2π 的位置。13.56 MHz 的波長是 22 公尺，除下來約 3.5 公尺——所以幾公分的感應卡穩穩落在近場，兩個線圈直接耦合，能量沒有「發射」出去。

門禁卡與旅館房卡

頻率同樣是 13.56 MHz，天線形狀、供電方式與負載調變都一樣，差別在協定。感應到門禁讀頭時，多數卡片只是把自己的識別碼送出去，系統再去資料庫查這組號碼有沒有權限、對應哪個房號。沒有挑戰與回應，沒有憑證鏈，也沒有一次性密文——所以複製容易得多。

最著名的案例是廣泛部署的某代非接觸卡片，其自訂加密演算法在 2008 年被完整逆向並公開，之後陸續出現能在極短時間內取出金鑰的手法，只要靠近卡片一段時間就能複製。後續世代改用標準的 AES 並加入雙向驗證，但舊卡至今仍在大量流通。臺灣的悠遊卡、一卡通同屬這個 13.56 MHz、Type A 的體系，安全等級則視實際採用的卡片世代而定。

圖書館與零售的防盜門

圖書館的書籍標籤多半仍是 13.56 MHz 的晶片標籤，只是出口那兩片門板裡的天線改成直立大線圈，好覆蓋整個門框的體積。書本通過時標籤回報識別碼，系統查到它沒有被辦理外借就觸發警報。

服飾店與賣場貼的軟標籤則更原始，裡面根本沒有晶片，只有一圈線圈加一個電容，構成一組調在 8.2 MHz 的共振電路。出口的門在同一頻率掃描，標籤共振時會把能量反射回去，門偵測到這個反射就響。結帳時櫃檯的消磁板做的事很暴力——以強場在標籤上感應出超過電容耐壓的電壓，直接把電容擊穿，共振點就此偏掉，再也不會回應。它不是被「關閉」，是被永久破壞。

遠場：倉儲盤點與高速公路

要在幾公尺外讀取，近場耦合完全不夠用，必須換一套物理。超高頻標籤把線圈換成偶極天線，工作頻率落在各地分配的 860 至 960 MHz 頻段（臺灣使用 920 至 925 MHz）。讀取器發出的是真正會自行傳播的電磁波，標籤用自己的偶極天線收下一部分能量開機，再藉由改變天線的反射特性把訊息送回去，稱為反向散射調變。

可以想像成讀取器拿手電筒照著標籤，標籤則交替把自己切換成鏡子與黑布，用反光的明暗回話。臺灣高速公路的 eTag 走的就是這套：貼在擋風玻璃上的被動式標籤，符合 ISO 18000-6C 規範，車輛以高速通過門架時由上方讀取器完成識別。倉儲一次盤點整箱貨品、賽事計時晶片也是同一類。

一秒鐘裡堆了多少東西

回頭看這條時間軸：法拉第在 1831 年寫下的感應定律負責供電；一組印在塑膠裡的電感與電容把能量放大到足以開機；兩套方向相反的編碼方案讓雙方在同一個磁場上輪流說話；三層憑證鏈證明卡片的身分；一套逐層分散的對稱金鑰把金額鎖死；最後才是那趟橫跨收單機構、卡組織與發卡行的網路來回。

這些層次沒有一層是裝飾。拿掉共振，卡片點不亮；拿掉修正式米勒編碼，長串的 0 會讓卡片斷電；拿掉副載波，回傳訊號會被自己的載波淹沒；拿掉憑證鏈，偽卡就能冒名；拿掉密文，被動過手腳的端末機可以隨意改金額。每一層都是在解決前一層製造出來的問題。

而這一切之所以值得，只是為了讓你在咖啡端上來之前把卡收回口袋。工程最徹底的成功，通常長得像「什麼事都沒發生」。
